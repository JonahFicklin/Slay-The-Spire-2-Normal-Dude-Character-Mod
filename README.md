# Slay The Spire 2 | Normal Dude Character Mod
This work in progress project adds a "Normal Dude" themed character who wields a gun. The character's cards are used to load the gun with ammunition and fire it. Still a work in progress, no custom assets have been created yet. 

No AI code is used to make this mod.

No AI art and assets are used.

## Installation
Extract files from SlayMySpire.zip and place the folder in the Slay The Spire 2 mods folder:
``\Steam\steamapps\common\Slay the Spire 2\mods``

## Known Bugs
- Certain cards have bugged descriptions
- Game freezes / crashes when giving a card reward
